## ⚠️ Before you start

1. Make sure **Git** and **Node.js (v18+)** are installed on your computer.
2. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/gauswamiashih/Ashish-Protfolio.git
   ```
3. Open your terminal in the root directory:
   ```bash
   cd Ashish-Protfolio/portfolio-app
   ```
4. Install all required dependencies:
   ```bash
   npm install
   ```
5. App is fully configured! Start the local dev server:
   ```bash
   npm run dev
   ```
6. Build the compiled production bundle:
   ```bash
   npm run build
   ```

## :camera: Key Features & Screenshots:

- 🌌 **Cyberpunk Holographic Core:** A floating, rotating avatar sphere displaying your stylized cybersecurity profile avatar, reacting to hover transforms.
- 🎛️ **Floating Capsule Navbar:** Modern center-aligned capsule nav with glassmorphism backgrounds (`backdrop-filter`), theme picker dot grid, and built-in scroll spy tracking.
- 🖥️ **3D Project Previews:** Custom browser mockup layouts (NagrikSetu dashboard map, Brotherhood Clothing storefront, Planto mockup) that pivot in 3D perspective (`perspective(1000px) rotateX() rotateY()`) on mouse hover.
- 📟 **Interactive Web Terminal:** Custom terminal command line interface accepting commands like `help`, `clear`, `about`, and `projects` with a typing terminal response log.
- 🌿 **Organic Canvas Particle Loop:** Floating canvas particles rendered inside the Planto plant storefront mockup for continuous, smooth organic motion.
- 🎨 **Multi-Theme Palette:** Toggle between Cyber Blue, Midnight Purple, Emerald Green, and Neon Pink themes instantly.
